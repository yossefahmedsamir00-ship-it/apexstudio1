# APEX STUDIO Admin App

Flutter admin application for the APEX STUDIO website.

## Purpose

A dedicated owner/admin app for managing the studio without exposing the web admin UI as the primary workflow.

## Planned modules

- Owner authentication
- Dashboard and analytics
- Projects
- Client requests
- Conversations/messages
- Orders and payment status
- Files/media
- Notifications
- Audit log
- Settings

## Stack

- Flutter / Dart
- Supabase Auth / Database / Storage
- GitHub repository and CI

The app is designed around the existing APEX STUDIO backend and owner authorization flow.
