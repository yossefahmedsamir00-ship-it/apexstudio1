# 07 — قرارات لم تُحسم بعد

هذه ليست عوائق تمنع إنشاء التصميم، لكنها يجب أن تُحسم قبل الإطلاق العام:

1. **هوية الاستوديو:** ملف الشعار النهائي، الخطوط المرخصة، وكتابة الاسم بالعربية عند الحاجة.
2. **محتوى الخدمات:** أي الخدمات متاحة للبيع الآن وأيها قيد التجهيز، والأسعار إن وجدت.
3. **وسائل الاتصال:** البريد، رابط WhatsApp، وحسابات الشبكات الاجتماعية التي تريد نشرها.
4. **سياسة الخصوصية والاحتفاظ:** الصياغة النهائية المناسبة للأسواق التي سيستهدفها الموقع.
5. **Admin UID:** لا يمكن كتابة صلاحية مسؤول فعلية قبل إنشاء الحساب ومعرفة UID من Firebase Auth.
6. **App Check:** تحديد المزود وإعدادات الويب قبل تفعيل النموذج العام على نطاق واسع.
7. **الاستضافة:** تأكيد مشروع Firebase المستقل وحدود Spark الفعلية في الحساب قبل النشر.
8. **مصدر الصور:** ملفات تملكها أو صور مرخّصة أو أصول تصميم أصلية؛ لا نستخدم الصور المرجعية التوضيحية باعتبارها أصول العلامة النهائية.
9. **التواصل الآلي:** البريد/WhatsApp الآلي مؤجل حتى تُختار خدمة وطريقة تشغيل صالحة دون افتراض التكلفة.
10. **متابعة العميل:** لا يوجد رابط تتبع طلب عام في MVP؛ رقم الطلب وحده لا يمنح وصولًا إلى البيانات.

## قرارات تم حسمها مبدئيًا

- ميزانية البداية صفر جنيه قدر الإمكان.
- الهدف التجاري الأول جذب عملاء لخدمات APEX STUDIO.
- شكل بصري أسود/Graphite وذهبي مع أزرق ولمسات حمراء محدودة.
- تجربة إبداعية أصلية، لا قالبًا عامًا واضحًا أنه مولّد آليًا.
- عربية وإنجليزية مع RTL/LTR.
- React + TypeScript + Vite مقترح للواجهة، وFirebase Hosting/Auth/Firestore مبدئيًا، وGitHub لإدارة الكود.
- لا Cloud Storage ضمن Spark؛ لا رفع ملفات في الإصدار الأول.
- لا AI API مدفوع أو payment gateway أو Marketplace ضمن MVP.
